# Batik identity revision

Revised the neutral workspace after feedback that it felt too plain. The design now uses deep teal (#155456), a botanical border on dark teal (#123f40), brass details, a pale green cloth canvas (#e8ebe0), and Libre Caslon Display headings with DM Sans controls. The SVG border is original decorative artwork; it is not presented as a historical or regional batik reproduction.

The single-screen guided structure, selection states, male/female options, camera guidance and countdown are preserved. Pattern copy now describes the visible botanical forms; the welcome screen reads “Your story, in batik.”

Validation: TypeScript and production build pass; git diff whitespace check passes. Desktop 1360 × 900 and mobile 390 × 844 visually reviewed. Mobile page width and height match the viewport with the next action visible. Existing lazy 3D chunk-size warning remains. No functional logic changed, so the previously passing 20 tests were not repeated.
